Synthetic UX research interview created for Phase 3 dataset development.

Moderator: Thanks for joining. Today we're evaluating a fashion e-commerce website. I'd like you to shop for a dress, save one item, and then explain how you would decide whether to buy it.
Participant: Sure. I usually start by searching for a specific product rather than browsing the whole catalog.
Moderator: Please find a black dress suitable for an evening event.
Participant: I'm looking for black dresses, and there are a lot of results. I can see filters, but I'm not immediately sure which one will help me narrow the list fastest.
Moderator: What would you try?
Participant: I would probably choose size first, then price. I don't see an occasion filter, which would actually be more useful for me.
Moderator: Can you find a dress under 100 pounds?
Participant: Yes. The price filter is easy enough. I can drag the range and the results update quickly.
Moderator: What do you think about the product cards?
Participant: The photos are good, but some cards don't show whether the item is available in my size. I have to open the product to check.
Moderator: Please open one product and decide whether you would consider buying it.
Participant: The product page looks clean. I like seeing several photos immediately, and the description is understandable.
Moderator: Can you find the material information?
Participant: Yes, that's easy. It's lower down the page, but the heading makes it obvious.
Moderator: What information is missing?
Participant: I would like a clearer fit indicator. It says true to size, but I don't know if that means I should order my usual size.
Moderator: Now save this item for later.
Participant: I see a heart icon, but I'm not completely sure whether that means save or like. I'll click it.
Moderator: What happened?
Participant: It changed color, but there wasn't any confirmation message. I assume it saved, but I would prefer a small confirmation.
Moderator: Now imagine you want to find this saved item tomorrow. Where would you go?
Participant: I would look for a wishlist. I can see my profile, but I don't immediately see wishlist in the menu.
Moderator: Try to locate it.
Participant: I had to open the account menu first. Wishlist is there, but it is buried under several options.
Moderator: How did that feel?
Participant: Slightly frustrating. I knew the feature existed, but I had to search for it.
Moderator: Would you return to the site to shop again?
Participant: Probably yes. The core shopping process is easy, and the product information is good. The wishlist navigation is the main thing I would improve.
Moderator: What would make the experience better overall?
Participant: Better filters, clearer size guidance, and easier access to saved items.
